# 🌐 Как устроен двуязычный сайт (RU/EN) — шпаргалка

## Структура

```
/                    ← русская версия (как раньше)
/en/                 ← английская версия
   index.html        ← главная EN
   methodology.html  ← методология EN
   diagnostics.html  ← диагностика EN (квиз полностью переведён)
   rune-map.html     ← карта рун EN
   port.html         ← лаборатория EN
   feedback.html     ← подписка EN
   menu.html         ← меню EN

books.json           ← данные о книгах НА РУССКОМ
books-en.json        ← данные о книгах НА АНГЛИЙСКОМ  ⚠️ парный файл!
runes.json           ← 24 руны на русском
runes-en.json        ← 24 руны на английском          ⚠️ парный файл!
projects.json        ← проекты лаборатории на русском
projects-en.json     ← проекты на английском          ⚠️ парный файл!
```

## Как это работает

Все JS-загрузчики (`load-menu.js`, `load-index-books.js`, `load-methodology.js`,
`load-runes.js`, `load-projects.js`) смотрят на адрес страницы:

- страница начинается с `/en/` → загружается `*-en.json` и английские подписи;
- иначе → русские данные, как раньше.

Переключатель 🌐 RU/EN в меню сам вычисляет адрес той же страницы на другом
языке (список переведённых страниц — в `load-menu.js`, константа
`TRANSLATED_PAGES`).

## ❓ Да, информацию о книгах нужно хранить и на английском

Это осознанное решение (стандартная практика для двуязычных сайтов):
автоперевод на лету ломал бы SEO и выглядел бы плохо. Поэтому:

### ✅ Добавили новую книгу — чек-лист:

1. Добавить книгу в `books.json` (как обычно).
2. Добавить ту же книгу в `books-en.json` — достаточно полей:
   `id, number, numberFull, title, subtitle, annotation, tag, status,
   statusText, litresLink` (для вышедших) или `url: "/en/feedback.html",
   action: "notify"` (для планируемых).
   Аннотацию можно сократить до 1–2 предложений — на EN-версии это нормально.
3. Если книга «вышла» — в `statusText` писать `"✅ Available (RU)"`,
   чтобы англоязычный читатель понимал, что книга на русском.

### ✅ Изменили текст на русской странице — не забыть:

- внести аналогичную правку в парную страницу в `/en/`.

### ✅ Добавили новую страницу и перевели её:

1. Создать копию в `/en/` и перевести.
2. Добавить имя файла в `TRANSLATED_PAGES` в `load-menu.js`.
3. Добавить в обе страницы hreflang-ссылки (см. любой пример, например
   `rune-map.html` ↔ `en/rune-map.html`).
4. Добавить EN-адрес в `sitemap.xml` (по образцу существующих записей
   с `xhtml:link`).

## Что осталось только на русском (осознанно)

- Страницы книг `book1.html…book25.html` — книги продаются на русском,
  отдельные EN-страницы пока не нужны (вся информация есть на `/en/#books`).
- `privacy.html` — юридический документ РФ.
- `404.html` — GitHub Pages поддерживает только одну страницу 404.

## SEO

- На каждой переведённой паре стоят `hreflang`-теги (ru / en / x-default) —
  Google и Яндекс сами покажут нужную версию нужной аудитории.
- `sitemap.xml` содержит обе версии с аннотациями hreflang.
- JSON-LD (структурированные данные) переведены на EN-страницах.
